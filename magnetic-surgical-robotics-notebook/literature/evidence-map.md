# Evidence Map

| Branch | Core question | Best current evidence to track | Typical weak point |
|---|---|---|---|
| Magnetic capsule robots | Can untethered GI devices navigate + intervene? | magnetic steering, biopsy/drug delivery, first-in-human endoscopy | force, localization, retrieval |
| Magnetic surgical tools | Can wireless tools grasp/cut/suture/aspirate? | Diller/Toronto, Leeds, Bhattacharjee lineage | task force + precise pose |
| Continuum/catheter robots | Can highly flexible tools steer safely in tortuous anatomy? | magnetic tips, distributed magnetization, FBG sensing | shape estimation + tissue contact |
| Intravascular robots | Can devices survive flow and stenosis? | guidewires, continuum microrobots, flow-aware control | pulsatility, thrombotic safety |
| Therapeutic microrobots | Can payload reach/release at target? | ETH clinical-ready platform | imaging + biodistribution + retrieval |
| Magnetic localization | Can small robots be tracked deeply without line of sight? | SMOL, magnetic sensors, X-ray/US fusion | actuation interference |
| Multi-agent/modular | Can global fields produce useful independent/cooperative behavior? | Sitti, Becker, Bhattacharjee modular work | underactuation |
| External actuator design | Can sufficient wrench be generated safely at depth? | coil arrays, EPM, local/hybrid actuation | depth, heat, singularities |
| Autonomy | Can medical imaging close the loop robustly? | NMPC, robust control, learned localization | latency, occlusion, model error |
