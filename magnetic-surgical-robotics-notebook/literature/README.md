# Literature

## What belongs here

Structured literature intelligence, not PDF dumps.

### Primary indexes
- `priority-reading.md` — papers we should deep-read now.
- `evidence-map.md` — technical/clinical taxonomy.
- `paper-notes/` — one note per deeply read paper (create as needed).
- `citation-mining-queue.md` — reviews/landmark papers whose references/citers need extraction.

## Deep-read standard

A paper is not “read” until we can state:
1. exact contribution,
2. equations/model,
3. hardware,
4. materials,
5. procedure,
6. validation environment,
7. strongest numerical result,
8. failure mode,
9. assumption likely to fail in vivo,
10. reproducible element,
11. plausible extension,
12. whether extension survives novelty search.
